# Phase game deck

The fixed 64-card deck for the native phase game sheet, generated by
`shakti_phase_deck.c` (pure C99, gauntlet-clean, -O0 == -O2).

**Deck pin: DC6E2CDB2761EC63** (2026-08-25)

Deck law: card k = wheel[k%5] ^ (k%4); cards where k%13==0 carry the
F7 shadow (value x13). The card generator and the engine
(`eden_phase.c`, pin EB32B4A547E3B901) are separate: the deck is data,
the engine is play. On the sheet, `phase_deck.txt` bundles as a
resource; the shell pins it at load and compares against the pin above
before a game may start. Drifted deck = no game, honestly reported.
